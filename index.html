How to read this dashboard

The map displays life expectancy by SA4 region using rolling 3-year windows to smooth short-term variations. Selecting an SA4 filters the rest of the charts. Use the window selector to switch timeframes; tooltips provide detailed values and ranks.

Key insights — Distribution & Gender Gap (01–02)

  • Most SA4s cluster in a narrow range of life expectancy, with few outliers.
  • The coloured histogram shows an inverse relationship between age-standardised mortality and life expectancy.
  • Dumbbell plots highlight the persistent gender gap — females outlive males across all regions.

Data Sources

  • ABS Life Tables by SA4 (persons/male/female), rolling windows 2016–2023.
  • ABS Age-standardised Mortality (per 100k), 2016–2023.
  • AIHW (Australian Institute of Health and Welfare) National Mortality Database, 2016–2023.
  • ABS Estimated Resident Population (ERP) – SA4 (for bubble sizing / rates).
  • ABS ASGS 2021 – SA4 boundaries (TopoJSON derived).

Methods & Notes

  • Life expectancy shown as rolling 3-year windows to smooth volatility.
  • Map uses Mercator projection with tuned scale/center to include Tasmania.
  • Interactions: SA4 selection (map → charts), window selector, histogram brush.
  • Units: years / per 100k; benchmark rules show national averages.
